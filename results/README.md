# Results Directory

This directory contains figures generated by the example scripts.

## Running the Examples

From the project root directory:

```bash
cd Insulin
julia --project=.
```

Then in Julia:

```julia
# Install dependencies (first time only)
using Pkg
Pkg.instantiate()

# Run examples
include("scripts/01_normal_regulation.jl")
include("scripts/02_type1_diabetes.jl")
include("scripts/03_type2_diabetes.jl")
include("scripts/06_bifurcation_analysis.jl")
include("scripts/07_drug_interventions.jl")
```

## Figure Descriptions

All figures are publication-quality PNG files with:
- Clear axis labels and units
- Informative titles
- Legends for multiple traces
- Reference lines for clinical thresholds
- Appropriate color schemes

## Reproducing Results

To regenerate all figures:

```julia
# From Julia REPL with project activated
for script in readdir("scripts"; join=true)
    if endswith(script, ".jl")
        println("Running $script...")
        include(script)
    end
end
```

Note: Some scripts take several minutes due to bifurcation analysis computations.

## Customization

To modify plots, edit the visualization functions in `src/Visualization.jl` or directly modify the plotting commands in each script.
